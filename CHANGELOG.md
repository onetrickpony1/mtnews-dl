# Changelog

## Unreleased

First version: the separate Maltese newspaper downloaders brought together in one package.

### Features
- **One command for every paper.** `mtnews-dl` runs `tom-dl` (Times of Malta e-paper and premium archive), `mttd-dl`
  (MaltaToday, Illum, BusinessToday and other MediaToday titles) and `talkmt-dl` (l-orizzont, it-Torċa), each also
  usable on its own with the same options.
- **Printed-date checks** on every PDF before it is filed, with a review queue for anything that doesn't match.
- **Times of Malta archive** through your own signed-in browser, within one daily page allowance shared by every
  library.
- **`doctor`** checks what is installed and offers to install the rest. **`--easy`** guides for each tool.
- **One-line installers** for Linux, macOS and Windows, plus double-click installers.
